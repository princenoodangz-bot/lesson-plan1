# ระบบจัดทำหลักสูตร → แผนการสอน
เว็บ static (HTML/JS) + Supabase + Gemini
แท็บ: โครงสร้างหลักสูตร → โครงสร้างรายวิชา → หน่วยการเรียนรู้ → แผนรายคาบ → ตั้งค่า (API Key หลายอัน สลับอัตโนมัติ)
ส่งออก Word (.docx) ตามรูปแบบแผนต้นฉบับ 12 หัวข้อ

Deploy: Cloudflare Pages, build command ว่าง, output directory = `/`
